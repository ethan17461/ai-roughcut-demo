# 截图证据

Demo 每一步的高清截图，文件名开头的编号就是先后顺序。

- **01–08**：第一版。16 段素材、存档脚本、系统语音。
- **09–13**：接入 DeepSeek 写脚本和 MiniMax 配音之后。在工作台输入选题现场生成，素材库 53 段。
- **14–15**：合并组员的成片评测第一版（AI 只初评 5 项，其余人工补分）。
- **16–17**：成片评测改版后。每秒 2 帧全检合规，21 个小项全部自动给分，转人工时只列出要人看的片段。这两张用的是按草稿合成的测试视频。
- **18**：用剪映真实导出的成片跑评测：72.5 分，合规三项未发现，结论是通过。
- **19**：剪辑 Skill 卡片。每条规则标了来源，并对照这条粗剪实际做到的数值；下半部分是蒸馏工具从成片量出来的值。
- **20**：换模型的实测记录。只改配置不改代码，写脚本和看图检查在 DeepSeek 和 MiniMax 之间切换都能跑通。
- **21**：一条视频的实测成本。6 条不同选题的平均：制作一条约 ¥0.12，成片评测约 ¥0.13。
- **22**：数据复盘卡片。导入两天的取数表，出作品日报，标出千播、待补和零播，把题材千播率回写到选题打分，并给出一条复测建议。发布记录和播放数是模拟的。
